- Snapping now starts from where your window actually is. Moved or resized one by hand? The first arrow press snaps it to the nearest size, and cycling continues from there.
- Stacks stay put: moving one stacked window no longer yanks the others back or reshuffles their order.
- Windows that refuse to shrink past a minimum size (Finder with its sidebar, Chrome) now stay fully on screen instead of hanging off the edge.
- Apps that round their own size (terminals, Spotify) no longer get stuck re-snapping to the same spot.
- Less work per keypress, and Sparkle (the auto-updater) is updated with its latest security fixes.

Apple Silicon only. Requires macOS 14+. If you're on an Intel Mac, v0.1.35 remains the last version for you.
