- Stacks are now **islands**. Snap two or more windows to the same spot and a slim tab bar appears above them: one tab per window, with its app icon and title. Click a tab to bring that window forward, drag tabs to reorder, or press your key combo + `Tab` to switch. Windows never move when you switch, so no more flicker.
- Prefer less on screen? Settings → *Island marker* → *Slim* swaps the tabs for a short row of dashes, the front one in its app's colour, plus a quick switcher when you change windows. This replaces the old *Peek size* setting.
- Arrows go where you point. Moved a window by hand? Its first arrow press moves it the way you pressed; press back toward where it was to snap it there.
- Islands stay put: moving one window out no longer yanks the others back or reshuffles them.
- Windows that refuse to shrink past a minimum size (Finder with its sidebar, Chrome) now stay fully on screen instead of hanging off the edge.
- Apps that round their own size (terminals, Spotify) no longer get stuck re-snapping to the same spot.
- Less work per keypress, and Sparkle (the auto-updater) is updated with its latest security fixes.

Apple Silicon only. Requires macOS 14+. If you're on an Intel Mac, v0.1.35 remains the last version for you.
